# 🌤️ Weather App

A simple and responsive **Weather Application** built using **HTML, CSS, and JavaScript**.
The application allows users to search for a city and view its current weather information through a clean and user-friendly interface.

## 📌 About The Project

The Weather App is a frontend web application developed using **HTML, CSS, and Vanilla JavaScript**.

Users can enter a city name and get weather information such as temperature, weather conditions, humidity, and wind speed.

This project was created to practice:

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* API Integration
* Fetch API
* Responsive Web Design
* Asynchronous JavaScript

## ⚙️ How It Works

The application follows a simple process:

```text
User enters city
        ↓
JavaScript gets city name
        ↓
Weather API request is sent
        ↓
API returns weather data
        ↓
JavaScript processes the response
        ↓
Weather information is displayed
```

## 🔑 API Configuration

If your project uses an API key, add your API key inside the JavaScript configuration.
